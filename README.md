# 5G Core Management Dashboard

## 🚀 Advanced Telecom-Grade Monitoring System

This is the frontend of the 5G Core Management Dashboard, deployed on GitHub Pages. For the full backend API and complete functionality, please visit the main repository.

### 🌟 Features

- **NF Heartbeat Table**: Real-time network function status monitoring
- **Log Viewer**: Tabbed logs for AMF, SMF, and UPF components
- **PDU Session Timeline**: Interactive timeline visualization
- **Alerts Panel**: Real-time system alerts with severity levels
- **Professional UI**: Modern design with animations and real-time updates

### 📱 Live Demo

Access the dashboard at: https://ashish7889.github.io/END-TO-END-5G-CORE-MANAGEMENT/

### ⚙️ Configuration

The dashboard is configured to connect to a backend API. For demo purposes, it will show mock data when the backend is not available.

### 📊 Dashboard Components

1. **Network Function Heartbeat**
   - Status indicators (UP/DOWN/UNREACHABLE)
   - Last heartbeat timestamps
   - Endpoint information

2. **Log Monitoring**
   - AMF, SMF, UPF log streams
   - Color-coded log levels
   - Auto-refresh functionality

3. **Session Timeline**
   - PDU session visualization
   - Active and completed sessions
   - Interactive tooltips

4. **System Alerts**
   - Real-time alert notifications
   - Severity-based coloring
   - Auto-refresh updates
